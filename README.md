# Smart Lab OS — Foundation

حزمة تأسيسية آمنة نسبيًا للبدء بتطوير Smart Lab OS دون حذف النسخة الموجودة في المستودع الأصلي.

## الموجود
- واجهة عربية متجاوبة.
- سجل خامات تجريبي يعمل محليًا باستخدام IndexedDB.
- قائمة محلية للتغييرات المعلقة.
- تصدير نسخة JSON.
- ملف PWA وService Worker لتخزين ملفات الواجهة.
- مخطط قاعدة بيانات أولي مقترح في `supabase/schema.sql`.
- خطة التنفيذ في `docs/PLAN.md`.

## مهم جدًا
**المزامنة السحابية وتسجيل الدخول غير مفعّلين.** التطبيق لا يرسل بيانات إلى Supabase حتى يتم إنشاء المشروع، وإعداد الاتصال، وإضافة سياسات RLS واختبارها. لا تستخدم النسخة الحالية لتشغيل مصنع أو حفظ بيانات حساسة.

## التشغيل محليًا
يفضل تشغيل الملفات عبر خادم محلي أو GitHub Pages/HTTPS؛ فتح `index.html` مباشرة قد يمنع Service Worker من العمل.

## النشر المقترح
ارفع ملفات الحزمة إلى مجلد مستقل أو فرع جديد أولًا، ولا تستبدل `README.md` الحالي أو تحذف الكود القديم قبل مراجعة الفرق وحفظ نسخة احتياطية.

## الملفات
- `index.html`, `styles.css`, `app.js`
- `manifest.webmanifest`, `sw.js`, `icon.svg`
- `supabase/schema.sql`
- `docs/PLAN.md`
